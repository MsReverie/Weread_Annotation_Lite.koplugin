# Weread Local Annotations

独立的 KOReader 插件：为本地 EPUB/TXT 等可重排文档显示微信读书划线和想法，支持预取、离线缓存和在线查看。

---


## 基于 (Based on)

本项目是在以下两个优秀项目的基础上进行二次开发：

- **[weread.koplugin](https://github.com/finlater/weread.koplugin)** 
- **[pickthought.koplugin](https://github.com/Mr54233/pickthought.koplugin)** 

结合二者的优势，重构了核心同步与 UI 层，使其更加轻量、稳定，通过在线拉取和章节预取的方式减少了api请求超限的情况，大幅加快下载进度的同时保有流畅的阅读体验。

---

## ✨ 主要功能

- **只读模式，安全无忧**：插件只获取微信读书的划线及想法内容，不会打开或下载微信读书的在线书籍，避免产生不必要的访问行为，对账号产生影响。
- **本地书籍匹配**：根据文件名或手动搜索微信读书书库，一键绑定本地书籍与线上书籍。
- **同步热门划线**：从微信读书获取当前书籍各章节的**热门划线**，并智能定位到本地文档的对应位置。
- **划线覆盖层**：划线与想法单独储存，不修改本地书籍；在阅读页面上以虚线高亮显示已匹配的划线，点击划线可查看相关「想法」。
- **想法按需加载**：点击划线时即时拉取想法。
- **智能预取**：自动预取当前章节及后续章节的想法，预取结果缓存到本地 SQLite 数据库，断网无碍阅读。
- **离线缓存**：所有划线、想法、章节索引均持久化存储，再次打开同一书籍瞬间加载。
- **断点续传**：同步或预取过程中可手动停止，即使拉取失败，再次启动时也能从中断处继续，不重复拉取已缓存的内容。
- **QR扫码登录**：一键生成二维码，微信读书 App 扫码授权，自动获取官方 API Key。

## 🔧 安装

1. 将本插件文件夹（`wereadannotationlite.koplugin`）复制到 KOReader 的 `plugins` 目录下。
2. 重启 KOReader，插件即加载完成（可在“工具”菜单中看到“Weread Annotation Lite”条目）。

---

## 🚀 使用说明

### 1. 登录微信读书账号

- 在工具菜单中点击 **“Weread QR login”**，弹出二维码。
- 打开微信App，扫描二维码并确认登录。
- 登录成功后，插件会自动获取官方 API Key，无需手动配置。

### 2. 匹配当前书籍

- 打开一本本地书籍（EPUB/TXT，CREngine 可重排格式）。
- 在工具菜单中选择 **“Sync underlines”**。
- 如果尚未匹配，插件会弹出搜索框，自动填入文件名关键词，您可搜索并选择正确的微信读书书籍。
- 匹配成功后，插件开始同步热门划线。

### 3. 同步划线

- 匹配成功后，同步将自动进行。
- 同步完成后，所有划线会显示在页面上。

### 4. 查看想法

- 点击任意划线区域，弹出想法弹窗。
- 想法弹窗支持**上下滑动查看**，**左右滑动或点击外部**即可关闭。

### 5. 预取想法

- 在菜单中开启 **“Auto prefetch thoughts”**（默认开启）。
- 打开书籍后，插件会自动预取当前章节及后续章节的想法（后台进行）。
- 您可在菜单中调节预取批次大小和延迟（高级选项，目前需修改设置文件）。

---

## ⚙️ 菜单选项说明

| 选项 | 作用 |
|------|------|
| **Enable underlines and thoughts** | 全局开关，关闭后划线和想法均隐藏，同时取消所有预取任务 |
| **Sync underlines** | 手动触发同步（若未匹配则先匹配） |
| **Auto prefetch thoughts** | 自动预取想法（开启后后台拉取） |
| **Show prefetch notifications** | 显示预取进度提示（默认关闭） |
| **Weread QR login** | 扫码登录/更换账户 |
| **Clear current book data** | 清除当前书籍所有缓存数据（包括划线、想法、章节） |

---

## 🗄️ 数据存储

- **数据库路径**：`koreader/data/WereadAnnotationLite/` 目录下，每本书对应一个 `.db` 文件（以书籍路径的 SHA256 前缀命名）。
- **设置文件**：`koreader/settings/wereadannotationlite.lua`，包含 API Key、Cookies、账户信息及用户偏好。
- **缓存策略**：热门划线按章节缓存，想法按划线范围缓存，均带时间戳便于更新。

---

## 📝 注意事项

- **支持格式**：仅支持 KOReader CREngine 可重排文档（EPUB、FB2、TXT、HTML 等），**不支持 PDF/DJVU 等固定布局文档**。
- **网络要求**：同步和登录需要网络，首次同步后所有数据可离线阅读。
- **账户安全**：API Key 和 Cookie 仅存储在本地，不会上传任何个人数据。
